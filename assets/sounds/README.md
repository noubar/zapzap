# ZapZap sound assets

`go.wav` is a shortened gameplay-ready derivative of `electric-zap-source.mp3`,
which was supplied by the project owner. It was trimmed, time-compressed to about
124 ms, filtered, attenuated, and faded out for responsive repeated playback.

The remaining WAV files are original synthesized cues produced by
`scripts/generate-sound-assets.js`. Running that script deliberately preserves
the imported GO sound.
